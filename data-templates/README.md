# KECHOO data templates

Use these templates to prepare the first public product and site information batch.

Recommended workflow:

1. Fill `products-public-lite.csv` first. This is enough for a quote-first public catalog.
2. Fill `company-launch-info.md` before deployment to `kechoo.com`.
3. Fill `shipping-rules-draft.csv` only with rules you are confident about. Unknown destinations can stay as `RFQ`.
4. Put product photos in folders named by SKU, then write the folder or filename in `image_files`.

For the first public version, do not worry about final online checkout fields. The site is currently RFQ-first, so price, stock, and PayPal can be completed later.
